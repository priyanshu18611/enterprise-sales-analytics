# Enterprise Sales Analytics — End-to-End Data Analytics Portfolio

**Priyanshu Kumar | Data Analytics / Software Engineering Portfolio**

## Project Overview
A complete, portfolio-ready enterprise sales analytics case study designed to demonstrate the workflow expected from a junior Data Analyst / BI Analyst:

**Raw data → validation → ETL → SQL warehouse → analysis → DAX → Power BI dashboard → Excel reporting → stakeholder insights**

The project uses a realistic synthetic sales dataset so no confidential/company data is exposed.

## Technology Stack
- **SQL:** MySQL 8+
- **Python:** Pandas, NumPy
- **BI:** Power BI, DAX
- **Spreadsheet:** Microsoft Excel
- **Data Modeling:** Star Schema
- **Development:** Jupyter, VS Code, Git/GitHub
- **Reporting:** Interactive HTML portfolio dashboard

## Key Business Questions
1. How are revenue and profit trending month over month?
2. Which regions generate the most revenue and profit?
3. Which categories/sub-categories have strong revenue but weak margins?
4. Which channels contribute the most orders and profit?
5. Which customers drive the highest revenue?
6. Are there data-quality issues before reporting?

## Validation Approach
- Required-column validation
- Duplicate order ID check
- Null key checks
- Negative revenue check
- Profit-vs-revenue consistency check
- Discount range validation
